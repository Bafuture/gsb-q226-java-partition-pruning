## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们的数据按时间分区存放，查询只涉及少数几个分区，现在每次都要扫全部分区。请从零实现一个表分区裁剪与分区级索引组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 支持按分区键（例如日期范围或哈希）把数据分到多个分区，每个分区维护自己的索引；2) 支持查询时的分区裁剪：根据查询条件中的分区键范围排除无关分区，需给出裁剪前后扫描的分区数对比；3) 支持分区内的数据查询：裁剪后在候选分区内做点查与范围查询；4) 支持分区新增与删除，删除分区时其索引一并清理，不得留下悬挂引用；5) 支持跨分区查询的合并与去重，结果要按指定键有序；6) 支持分区元数据统计：每个分区的键范围、条数与索引大小；7) 说明分区键选择对裁剪效果的影响，并给出不同选择下的对比；8) 测试覆盖分区写入、裁剪生效、分区内查询、分区删除清理、跨分区合并与统计；`mvn -q verify` 一条命令跑通。
